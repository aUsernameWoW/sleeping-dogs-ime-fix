SDIMEFix · 游戏原生风格

用《热血无赖》自己的菜单部件拼出的 LOGO：琥珀辉光标题字、墨迹底板、霓虹描边输入框、UI 校准角框。右侧是"输入法在这个游戏里本该长的样子"：组字和候选词直接画在游戏内的界面里。横幅文案只说游戏缺了输入法支持，不点名 ReShade。

横幅

图标

同一个图形缩到 32 px 仍然认得出，可以做 GitHub 头像、Nexus 图标或者 favicon。

取材

  • 标题字CCHAR_*
    菜单标题的琥珀辉光繁体字，这里写「中文輸入」
  • 输入框BACKING_9SLICE_SLOT / SLOTWIDE
    琥珀霓虹描边、暗红褐填充的圆角框
  • 选中的候选BACKING_9SLICE_FILL
    奶油色实心高亮，游戏里表示当前选项
  • 墨迹底板BACKING_9SLICE_LARGE / GRIT
    标题后面粗糙的黑色笔刷
  • 角框BACKING_UISCALECORNER
    画面校准时屏幕四角的 L 形辉光
  • 飘带SD_LOGO_TEXT_DE
    只借用红色斜切飘带的形式，不用官方字标和盾牌
